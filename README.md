# 🎙️ Aprende IA con Claude — de nivel 0 a nivel 100

Un curso en español, muy fácil de seguir, para aprender a usar la inteligencia artificial (Claude) **usando la voz**.
Pensado para personas que nunca usaron IA, que aprenden a su ritmo y que prefieren no escribir con el teclado.

**No necesita ningún servicio pago.** Todo se puede hacer con el plan gratis de Claude.

## ▶️ Cómo abrir el curso

### Opción 1: desde internet (lo más fácil)
Abre el link de GitHub Pages del curso en Chrome o Edge y guárdalo en favoritos ⭐.

### Opción 2: descargado en la computadora (funciona sin internet)
1. Descarga el archivo **`curso-ia-claude.zip`** (en la sección *Releases* de este repositorio, o con el botón verde **Code → Download ZIP**).
2. Haz clic derecho sobre el ZIP → **Extraer todo**.
3. Abre la carpeta y haz **doble clic en `index.html`**.
4. Consejo: clic derecho en `index.html` → **Enviar a → Escritorio (crear acceso directo)**.

> Sin internet, el curso se ve y funciona igual. Los videos y Claude sí necesitan internet.

### Opción 3: en el teléfono 📱
Abre el link de GitHub Pages en Chrome (Android) o Safari (iPhone). El curso **detecta que es un teléfono** y cambia las instrucciones: micrófono del teclado en vez de Windows + H, capturas de pantalla con una mano, menús de la app de Claude, etc.
En la portada explica cómo **ponerlo en la pantalla de inicio** como una app; así también funciona sin internet.
Si la detección se equivoca, abajo en la portada hay un botón para cambiar entre versión teléfono y computadora.

## ✨ Qué tiene

- **11 lecciones** (nivel 0 → nivel 100): qué es la IA, dictado por voz, cuenta de Claude, primeras conversaciones, cómo pedir bien las cosas, fotos y documentos, artefactos, **diseño gráfico con IA**, proyectos y modo voz, Claude Code / Claude Design, seguridad y diploma.
- 🔊 **Botón para escuchar** cada cuadro en voz alta (mejor en Microsoft Edge, que tiene voces naturales en español).
- 🚀 **"Abrir en Claude"**: abre Claude con la frase ya escrita. 📋 **"Copiar"** como alternativa.
- 🔠 Letra más grande / más chica, modo oscuro y **alto contraste**.
- ⭐ Guarda el progreso y las misiones en el navegador.
- ⬅️➡️ Cambiar de lección con las flechas del teclado (cómodo con una mano).
- 💬 Frases listas, 📖 diccionario y 🤝 **guía para el acompañante** (con checklist de preparación y tarjeta para imprimir).
- 🎓 Diploma imprimible al final (el nombre se dicta con la voz).

## 🛠️ Cómo cambiar el contenido

Todo el texto del curso está en **`lecciones.js`**. Ábrelo con el Bloc de notas o VS Code, cambia lo que quieras y guarda.
- `estilos.css` → colores y tamaños.
- `app.js` → funcionamiento (botones, voz, progreso).

## 🔊 Audios (voz de mujer y de hombre)

Todo lo que el curso lee en voz alta está **grabado** en la carpeta `audio/` (una carpeta por voz), así suena igual en cualquier computadora o teléfono, también sin internet.
Las voces son de [Piper](https://github.com/rhasspy/piper), gratis y de código abierto.

Si cambias un texto en `lecciones.js`, ese cuadro se leerá con la voz del aparato hasta que se vuelva a grabar.
Para regrabar solo lo que cambió, sigue las instrucciones al inicio de `herramientas/grabar-audios.js` (o pídeselo a Claude Code).

## 📝 Nota

Claude y las herramientas de IA cambian seguido: algunos botones o nombres pueden verse distintos. Los videos son búsquedas de YouTube para que siempre aparezcan videos actuales.
